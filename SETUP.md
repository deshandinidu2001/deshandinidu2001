# Publish your profile

1. Create a **public** GitHub repository named `deshandinidu2001`, matching your username exactly. If it already exists, use that repository.
2. Upload `README.md` and the entire `assets` directory to the root of its default branch.
3. Visit https://github.com/deshandinidu2001 to see the profile README.

Open `preview.html` locally for a design preview. GitHub applies its own Markdown layout; the preview is illustrative, not an exact GitHub rendering. Animations live inside `assets/header.svg`; project cards are links, and README details sections expand on click. No JavaScript or hosting is required for the profile.

The profile uses public GitHub data verified during creation. The interests paragraph is proposed editable copy. No university, employer, contact email, availability, or unverified project descriptions have been added.

Edit the text in `README.md`. To change artwork, edit `scripts/build_assets.py`, then run `python scripts/build_assets.py`. The toolkit badges use Shields.io; the banner and project cards are stored locally.

Only `README.md` and `assets/` are needed on GitHub. Keep this guide, the generator, and the preview if useful.
